# Site — 1 ano e 1 mês ♥

## Como usar
1. Abra `index.html` no navegador.
2. Coloque suas fotos em `assets/fotos/` com estes nomes:
   - foto1.jpg
   - foto2.jpg
   - foto3.jpg
   - foto4.jpg
   - foto5.jpg
3. Coloque a música em `assets/musica.mp3`.
4. Abra `script.js` e altere:
   - `START_DATE` se a data de início estiver diferente. A versão atual usa 12/07/2025 para representar 1 ano e 1 mês em 12/08/2026.
   - `QR_LINK` para o link que o QR Code deve abrir.
   - `SECRET_MESSAGE` para a mensagem do cantinho secreto.

## Observação
O QR Code usa uma biblioteca carregada pela internet. A música é local e deve estar em `assets/musica.mp3`.

## Próxima personalização
Esse é o esqueleto visual premium. Dá para personalizar nomes, datas, textos, fotos, música, cores, efeitos, frases e criar páginas/áreas extras sem mudar a estrutura.
